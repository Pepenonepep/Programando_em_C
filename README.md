### 📁 Structure

* `Root files (.c)`: Standalone exercises covering fundamental C concepts (e.g., math operations, geometry checks, validations).

### 🚀 How to run
1. Clone this repository: `git clone https://github.com/Pepenonepep/Programando_em_C.git`
2. Open the project in your favorite IDE (VS Code, Code::Blocks) or terminal.
3. Compile the specific `.c` file using a compiler like GCC: `gcc filename.c -o program`
4. Run the compiled executable: `./program` (Linux/Mac) or `program.exe` (Windows).

### 📁 Estrutura
* `Interesting_problems_beecrowd/`: Minhas resoluções para desafios de lógica e algoritmos da plataforma Beecrowd.
* `Arquivos na raiz (.c)`: Exercícios independentes abordando conceitos fundamentais de C (ex: operações matemáticas, checagens geométricas, validações).

1. Clone este repositório: `git clone https://github.com/Pepenonepep/Programando_em_C.git`

3. Compile o arquivo `.c` específico usando um compilador como o GCC: `gcc nome_do_arquivo.c -o programa`
4. Execute o arquivo compilado: `./programa` (Linux/Mac) ou `programa.exe` (Windows).
